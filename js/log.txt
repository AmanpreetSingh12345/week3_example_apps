Flask implementation: Flask stored the board in Python memory on your computer/server. Every click refreshed the entire page, requesting /set/<id>. If you opened the site in two separate tabs, both tabs shared the same single game because the server held the board.

Vanilla JavaScript implementation: The server only acts as a simple file delivery system. 
It gives you index.html and tictactoe.js once. 
From that millisecond onward, Python/Flask is out of the loop. 
The board lives inside the browser tab's volatile RAM.
